# MicaLingo - German Exam Preparation

This is a React-based web application built with Vite to help users prepare for German language exams.

## Features
- Vocabulary practice
- Grammar quizzes (Articles, Prepositions, etc.)
- Custom quiz generation from user-imported data
- Progress tracking and statistics
- Multi-language support (English, German, Hungarian)

## Tech Stack
- React
- TypeScript
- Vite
- Tailwind CSS
- Firebase (Authentication & Firestore)

## Getting Started

1.  **Install dependencies:**
    ```bash
    npm install
    ```

2.  **Run the development server:**
    ```bash
    npm run dev
    ```
