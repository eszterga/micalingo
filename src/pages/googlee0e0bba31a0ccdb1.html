# PROJECT_SPEC.md **Project Name:** MicaLingo (MVP) **Version:** 2.0 (Simplified) --- # 1. Vision Build an offline-first language learning web application that transforms **user-provided learning materials** into interactive quizzes. The system is NOT AI-dependent. The system is NOT cloud-dependent. It is a **personal learning tool** that works locally in the browser. --- # 2. Core Idea User provides materials: * vocabulary lists * sentences * Excel files * text files * copied text The application: 1. extracts learning items 2. stores them locally 3. generates quizzes from them 4. tracks progress 5. adapts repetition based on mistakes --- # 3. Main Goal > Turn static learning materials into active practice. No manual quiz creation is required. --- # 4. Target Users * German learners (initial focus: German → Hungarian) * TELC / Goethe / ÖSD exam candidates * self-learners * students * language hobby learners --- # 5. Platforms Single codebase: * Web app (React) * Progressive Web App (PWA) * Mobile browser compatible Optional future: * Android / iOS wrapper (Capacitor) --- # 6. Core Features ## 6.1 Import System Users can import: * TXT * CSV * Excel (basic parsing) * Copy-paste text System extracts: * words * sentences * simple grammar hints (if available) --- ## 6.2 Vocabulary System Stores learning items locally. Each item may contain: * German word * Hungarian translation * English translation (optional) * example sentence * tags * category * grammar notes (optional) --- ## 6.3 Quiz System Automatically generates exercises: * flashcards * fill-in-the-gap * multiple choice * translation * word ordering No AI required. Uses rule-based templates. --- ## 6.4 Grammar System (Simple Version) Supports: * basic Dativ / Akkusativ rules * article selection (der/die/das + forms) * simple adjective endings (basic level) * fixed prepositions list * verb + case mapping table --- ## 6.5 Practice Mode User can: * start quiz session * answer questions * get instant feedback * see correct answers * retry mistakes --- ## 6.6 Scoring System Tracks: * correct answers * incorrect answers * accuracy % * weakest topics * strongest topics * repetition history Stored locally. --- ## 6.7 Adaptive Learning (Rule-Based) No AI. System increases repetition of: * wrong answers * weak grammar topics * recently failed items System decreases repetition of: * mastered items --- ## 6.8 Offline First Everything works without internet. All data stored in browser (IndexedDB). --- # 7. Non-Goals (IMPORTANT) This project DOES NOT include: * backend server * authentication system * cloud sync * AI integration (for MVP) * API keys * real-time collaboration --- # 8. Success Criteria The MVP is successful if: * user can import text * system extracts vocabulary * quizzes are generated automatically * user can practice * progress is saved locally * system works offline --- # 9. Future Expansion (Optional) Later versions MAY include: * AI-generated exercises * OCR from images * PDF import * speech recognition * pronunciation training * advanced grammar engine --- # End of PROJECT_SPEC.md (MVP)
